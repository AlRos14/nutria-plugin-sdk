# Quickstart: a schema 3.0 plugin

## Install and scaffold

```bash
uv add nutria-plugin==0.3.1
nutria-plugin new inventory-lookup --name "Inventory Lookup"
```

## Define plugin.json

```json
{
  "schema_version": "3.0",
  "id": "inventory-lookup",
  "name": "Inventory Lookup",
  "version": "0.1.0",
  "description": "Reads authoritative warehouse stock.",
  "author": "Acme Corp",
  "runtime_types": ["declarative_api"],
  "required_secrets": ["WAREHOUSE_API_KEY"],
  "remote_endpoints": ["https://api.warehouse.example"],
  "capabilities": [{
    "id": "warehouse.stock.read",
    "title": "Read stock",
    "description": "Read current stock for one SKU.",
    "effect": "read",
    "tool": "get_stock",
    "connection_id": "warehouse",
    "requirements": {
      "authority": "read",
      "audience": ["team_internal", "public_customer"],
      "task_context": "optional"
    },
    "exposure": "model",
    "produces": [{
      "result_path": ".stock",
      "resource_type": "warehouse.stock",
      "output_name": "stock"
    }]
  }],
  "world_providers": [{
    "id": "warehouse",
    "title": "Warehouse",
    "description": "Authoritative warehouse inventory.",
    "connection_id": "warehouse",
    "resource_types": [{
      "id": "warehouse.stock",
      "title": "Stock item",
      "description": "Current stock identity and state.",
      "identity_fields": ["sku"],
      "search_capability": "warehouse.stock.read"
    }]
  }]
}
```

Add the matching declarative connection and skill files generated by the
scaffold. Assign the connection through the persona's `allowed_connections`;
the manifest does not own persona assignment.

## Validate and package

```bash
uv run nutria-plugin validate inventory-lookup
uv run nutria-plugin pack inventory-lookup \
  --output inventory-lookup-0.1.0.zip
```

Any schema 2.0/2.1 field, unknown property, missing provider, or incomplete
authority/exposure contract fails validation and must be corrected explicitly.
